修改元素:

切片操作:将一个列表切分成多个列表
变量[起始下标:结束下标]     #结束下标取不到
1.下标从0开始可以不写
2.如果下标取的是最后一个元素,可以省略不写

n=[开始:结束:步长]

列表操作符:
1.比较运算：相同下标进行比较,从小到大,值相同即比较下一个,不同则直接输出结果
2.逻辑运算符：and not or，返回值是布尔值
and 若左为真，返回右边的值，左为假，返回左边的值
空列表为假，其余皆为真
3.拼接运算符：+用来做两个列表的拼接
4.重复运算符：*用来表示列表的元素重复几遍
5.成员关系操作符：in/not in,返回值是布尔值，用于判断元素是否在列表中

冒泡排序：
l = [6, 5, 4, 3, 2, 1]
for i in range(1, len(l)):  # 1,5 #循环4大次  4
    for j in range(len(l) - i):
        if l[j] > l[j + 1]:
            l[j], l[j + 1] = l[j + 1], l[j]

print(l)

选择排序
l = [6, 5, 4, 3, 2, 1]
for i in range(0, len(l) - 1):  # 0,4
    for j in range(i + 1, len(l)):  # 1,5
        if l[i] > l[j]:
            l[i], l[j] = l[j], l[i]

print(l)

元组(tuple)
1.不可修改，不可变类型
2.用()的形式
3.是可迭代对象
4.是有序的，用下标操作，支持切片操作t[1:3],不含最后下标的元素

要修改可以将元组改成列表再在修改，最后将来列表转换成元组
分别使用list  tuple函数
eg:
t = (1, 2, 3, 4, 5)
l = list(t) #将元组转换成列表
print(l)    #输出列表
l[2] = 6    #列表指定元素的修改
print(l)    #输出新列表
t = tuple(l)    #列表转换成元组
print(t)

函数
由一组代码组成，完成某个特定的功能

创建和使用
def 函数名(参数): 
	代码块（函数的实现/函数体）

函数名(参数)

运行机制：
从函数调用开始执行
用名字找到函数定义的位置
执行函数体
执行完毕，回到函数调用处

定义函数的时候传递的参数是形参
调用函数的时候传递的参数是实参 
实参和形参要一一对应

用形参的名字作为关键字指定具体传递的值，则调用时前后顺序不受影响

给了默认值的参数--形参
若传递新的值则默认值被覆盖

可变参数：
	def 函数名(*a)
	本质上封装成了元组

可变参数：
	def 函数名(**kwargs)
		将参数封装成了字典

可变参数和位置参数混用的时候，可变参数优先 

函数文档:
标准化,在函数体的第一行用"""   """进行文档说明
可以获取函数文档的内容
    函数名.__dco__
可以用help(函数名)函数进行查看

函数返回值
return
谁调用就返回给谁
任何函数都有返回值
不写return 默认返回None
写return不写返回值和不写return的效果相同
可返回任何数据类型
return代表函数结束,后面的不执行

局部变量
全局变量
冲突时,以局部变量优先
global      声明全局变量
nonlocal    声明局部变量

内嵌函数
要用nonlocal和global才能进行a=a+1这样的操作

闭包
内部函数调用外部函数的局部变量，外部函数返回内部函数的函数名
作用是传递更少的形参，可以传递更多的实参，更安全，间接性的访问内部函数
