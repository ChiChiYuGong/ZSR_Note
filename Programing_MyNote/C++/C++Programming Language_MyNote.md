#### 2.2.2 类型、变量和算数运算

####  2.2.3 常量

C++支持两种不变性概念
1.const:承诺不改变这个值,作用是变量传入函数不用担心在函数内被改变,编译器负责确认并执行const的承诺
2.constexpr:在编译时求值,作用是允许将数据置于只读内存中以及提升性能(其声明的表达式中必须要有常量,不然会报错)

*常量表达式(constant expression)*
某个函数用下常数表达式中即该表达式在编译时求值,则函数必须为constexpr
C++一个值别算出来可以在编译期,也可以在运行期
有些位置天生要求编译期算好一个常数(即常量表达式)
想要在这种地方调用某个函数,那个函数必须声明为constexpr
·承诺给编译器,给常量参数,并保证能算出常量结果
·请求给编译器,参数在编译期已知就算出来

constexper加在函数上允许编译期求值
加在变量上编译期初始化

要定义成constexpr的函数必须非常简单,只有一条用于计算某个值的return语句
constexpr函数可以接受非常量实参,但结果不是一个常量表达式
所以一个函数有两个用法,一个用于常量表达式,一个用于变量

### 2.3 用户自定义类型

#### 2.3.1 结构

构建新类型的第一步将所需元素组织成一种数据结构
struct Vector{      //初代vecotr

new运算符从*自由存储*(free store)区域分配内存

#### 2.3.2 类

理想的做法是把类型的接口(所有代码都可使用的部分)与其实现(对其他不可访问的数据具有访问权限)分离开来
这种机制称为*类*(class)
类含有一系列*成员*(member)
成员可以是数据,函数,类型
类的public成员定义该类的接口,private成员只能通过接口访问
**例**
class Vector {                                   // ① 定义一个新类型，名字叫 Vector
public:                                          // ② 从这里开始的成员，外部可以访问
    Vector(int s) :elem{new double[s]}, sz{s} { }   // ③ 构造函数
    double& operator[](int i) { return elem[i]; }   // ④ 让对象能用 v[i]
    int size() { return sz; }                       // ⑤ 返回元素个数
private:                                      // ⑥ 从这里开始的成员，只有类内部能访问
    double* elem;   // 指向元素的指针
    int sz;         // 元素的数量
};                                               // ⑦ 类定义结束，这个分号不能省

类的定义结束后;不能省

elem{new double[s]}
意思是用new在堆中申请s个double的连续空间，返回首元素地址，存进elem 
{}是赋值的新写法
最后的{}空函数体表示初始化列表结束


这样的Vector对象是一个句柄,包含指向元素的指针以及元素的数量等，不同对象中元素的数量可能不同，而对象本身的大小永远不变

与所属类同名的函数称为*构造函数*(constructor)
用来构造类的对象的函数
没有返回类型，创建对象时自动调用
:后面的部分是成员初始化列表

运算符重载
函数名=关键字+运算符符号

例:下标函数     operator[]

#### 2.3.3 枚举

枚举值位于作用域(enum class)中，因此可以在不同的enum class中重复使用这些枚举值

枚举类型常用于描述规模较小的整数值集合
通过使用有指代意义的枚举值名字提高代码的可读性，降低出错风险

enum后面的class指明了枚举是强类型的，且枚举值位于指定的作用域中
不同的enum class是不同的类型，有助于对常量的意外误用

### 2.4 模块化

一个C++包含许多独立开发的部分
构建程序的关键是清晰地定义这些组成部分之间的交互关系
将某个部分的接口和实现离开来
C++使用声明描述接口
*声明*(declaration)指定了某个函数或某种类型所需的所有内容

#### 2.4.1 分离编译

用户代码只能看见所有类型和函数的声明，定义则放置在分离的源文件里，被分别编译
将一个程序组织成一组半独立的代码片段
编译时间减少
一个库通常是一组分离编译的代码片段的集合

描述模块接口的声明放置在一个特定的文件中，文件名常常指示模块的预期用途
这种文件称为*头文件*(header file),用户将其*包含*(include)进程序以访问接口

负责提供模块实现部分的.cpp文件也有包含提供接口的.cpp文件,用于定义模块

#### 2.4.2 名字空间

C++提供了一种称为*名字空间*(namespace)的机制
表达某些声明是属于一个整体的
表面名字和其他namespace中的名字冲突

将代码放在名字空间中，可以确保名字不会和其他标准库的名字冲突
要访问其他名字空间的某个名字,在名字前加上名字空间的名字作为限定
std::out代表使用std名字空间中的out函数

main()定义在全局名字空间中，不属于任何自定义名字空间,类或函数

要获取名字空间中名字的访问权，应该用using指示
using namespace std;

名字空间主要用于组织较大规模的程序组件,如库.可将若干部件组织成一个程序

高层次的结构简化程序设计,减少了产生错误的机会，同时增加编译器捕获错误的概率
随着程序规模的增长，库的应用变广泛，处理错误要有规范和标准

##### 2.4.3.2 不变式

*前置条件*(precondition)没有得到满足，函数拒绝执行
对于类来说，一条假定某事为真的什么称为*类的不变式*(class invariant),简称为*不变式*

### 6.1  ISO C++标准

很多重要功能都是*依赖于实现的*(implementation-defined)
大多数依赖于实现的功能都与运行程序的硬件系统相关

另一种行为是*不确定的*(unspecified),意味着几种行为都有可能发生
new运算的返回结果是不确定的

常常交给你所有依赖于硬件的类型尺寸以级及定义放在头文件中
numeric_limits
可以通过设置静态断言的方式检查某些特性是否确实依赖于实现的

如果具体实现无法为某一关指定明确合理的行为，则认为是*未定义的*

应确保程序中没有不确定的或是未定义的部分
